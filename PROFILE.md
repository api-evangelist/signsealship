# SignSealShip Partner API

A pay-per-use platform to sign, notarize (including remote online notarization / RON), and ship documents, producing cryptographic evidence with public verification URLs. The partner API adds Verified Closing Rooms and sealed, versioned Closing Passports, plus a free open dataset of RON requirements.

## APIs

- **SignSealShip Partner API** — REST API to sign, notarize, and ship documents, manage Verified Closing Rooms, seal Closing Passports, and verify evidence. OpenAPI 3.1 contract with 35 paths, bearer partner-key auth. (`https://signsealship.com`)
- **RON Requirements Open Dataset** — Remote online notarization requirements for all 51 U.S. jurisdictions (50 states + DC), with effective dates, fee caps, identity-verification standards, retention periods, and primary-source citations. Licensed CC BY 4.0. (`https://signsealship.com`)
